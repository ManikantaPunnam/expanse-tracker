Expense Tracker (Python CLI)
A simple and beginner-friendly Expense Tracker built using Python. This command-line application allows users to record, view, and calculate their expenses efficiently.
Features
- Add new expenses with details
- View all recorded expenses
- Calculate total spending
- Easy-to-use menu-driven interface
Tech Stack
Language: Python
Interface: Command Line (CLI)
Project Structure
expense-tracker/
│
├── expance.py
└── README.md
Getting Started
Prerequisites:
- Python 3.x installed

Run the Project:
python expance.py
Usage
1. Add Expense
2. View All Expenses
3. View Total Expenses
4. Exit
Limitations
- Data is not stored permanently
- No database or file storage
- Minimal input validation
