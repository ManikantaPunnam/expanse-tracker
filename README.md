# 💰 Expense Tracker (Python CLI)

A simple and beginner-friendly **Expense Tracker** built using Python.  
This command-line application helps users record, view, and calculate their expenses easily.

---

## 🚀 Features

- Add new expenses  
- View all recorded expenses  
- Calculate total spending  
- Simple menu-driven interface  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Interface:** CLI (Command Line)  

---

## 📁 Project Structure

    expense-tracker/
    │
    ├── expance.py
    └── README.md

---

## ▶️ Getting Started

### Prerequisites
- Python 3.x installed  

### Run the Project

    python expance.py

---

## 📌 Usage

    ==== MENU ====
    1. Add Expense
    2. View All Expenses
    3. View Total Expenses
    4. Exit

---

- No database integration
