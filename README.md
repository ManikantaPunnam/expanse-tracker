# 💰 Expense Tracker (Python CLI)

A simple and beginner-friendly **Expense Tracker** built using Python.  
This command-line application helps users record, view, and calculate their expenses easily.

---

## 🚀 Features

- ➕ Add new expenses  
- 📋 View all recorded expenses  
- 💵 Calculate total spending  
- 🧾 Simple menu-driven interface  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Interface:** CLI (Command Line)
